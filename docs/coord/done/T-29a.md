time_basis_note: |
  Trigger: the first time the panel displays the opening stage, which it learns
  from progress.initial.current_stage_id rather than from a stage name in the
  script. docs/CHAPTER_TIMELINE.md places the explanation there.
  Dismissal: it goes when the run moves past that stage, and can also be closed
  early through dismiss_time_basis_note(). It does not return on a later visit to
  the opening stage; shown once is shown.
  It never blocks. It is a label inside the panel, not a modal, so it creates no
  player action, which is what docs/CHAPTER_TIMELINE.md requires of it.
  Verified in both directions: visible after the first stage-one load, gone after
  advancing to stage two, and still gone after loading stage one again.

  rectangle belongs to whoever assembles the scene. The panel anchors to the top
  edge with PRESET_TOP_WIDE and writes no coordinate at all, which means the
  layout can be retuned in the editor without touching this script.
  Checked mechanically rather than by reading: the code contains no occurrence of
  position, size, Rect2, offset_top, offset_left, set_position or set_size, with
  comment lines stripped first so the check cannot pass on a technicality or fail
  on a comment.

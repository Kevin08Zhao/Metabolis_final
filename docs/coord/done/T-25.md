the_six_conditions: |
  Judged one by one, and reported by name so a caller can show exactly which is
  outstanding rather than a bare false.
    all_stages_complete        ChapterFlow.is_run_complete()
    organ_systems_established  every id in chapters.stage_birth.required_organ_ids
                               has been reported through organ_built
    birth_check_passed         BirthMachine.gate_passed()
    birth_transition_complete  BirthMachine.birth_transition_complete
    first_breath_started       the machine has reached its terminal ending state
    ending_viewed              BirthMachine.first_breath_complete, which is only
                               true once the ending picture has held its full
                               window, so the player has actually seen it
  The last two are deliberately distinct. Arriving at the ending starts the first
  breath; the window elapsing is when it has been watched. Collapsing them would
  let the run close on a finale the player never saw.

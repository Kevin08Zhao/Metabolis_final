  affects the player, which is a judgement this task has to make. Each of the
  three is mapped to the earliest point a player could feel it rather than read
  it, and each mapping is an existing event, so no new detection logic exists:
    network_efficiency_coefficient - transport_pressure_appeared. The network's
      capacity first limits delivery, which is where a weaker carried network
      stops being a number and starts costing throughput.

      of the stage resolves against a pressure the player did not create here.
    initial_waste_accumulation - waste_buildup_appeared. Waste first surfaces as
      a bottleneck rather than as a readout.
  Stage one explains nothing, and that falls out of it having no carryover record
  rather than out of a stage-name check.

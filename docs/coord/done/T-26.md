for_t27_to_know: |
  save_version is written as the integer 1 but reads back as the float 1.0.
  Godot's JSON parser returns every number as a float regardless of how it was
  written. T-27's version comparison must cast before comparing, and must not
  test the type. Recorded here because a strict equality against an int would
  silently treat every save as a version mismatch and trigger the downgrade path
  on a perfectly good file.
snapshot_write_timing: |
  record_stage_snapshot is called by the chapter flow state machine before it
  enters step one, and refuses every later call for that stage. The refusal is
  the whole point: an autosave later in the same stage must not overwrite the
  state the stage began with, or replaying that stage would resume from its
  middle rather than its start.
  The prompt asks for a "snapshot already written" flag. It is kept as the set of
  stage ids that have one, and adopt_loaded_blocks rebuilds that set from the
  snapshot block after a load, so the flag and the data cannot drift apart. A
  parallel boolean would have been a second source of truth for the same fact.

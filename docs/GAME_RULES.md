# Player Action Rules

This document defines the complete set of executable player actions in Metabolis: Birth of the City of Life. The system accepts only the six actions in the table below. Observing status, receiving objectives, settling resources, completing construction, observing system collaboration, unlocking science content, and carrying state forward are system steps, not additional player actions.

## Evaluation Conventions

- Every action request first evaluates its entire prerequisite. If the expression is `true`, costs and effects execute atomically. If it is `false`, game state does not change and the corresponding rejection feedback executes.
- `&&` means logical AND, `!` means logical NOT, `in` means set membership, `is_subset_of` means every member of the left set exists in the right set, and `null` means no object is selected.
- `balance.*` denotes a read-only balance-configuration path. Every tunable value in the table is read from such a path.
- “Enter and skip or complete a minigame” is one complete action transaction. Entering, skipping, and completing are not separate actions.
- `selected_*` and `requested_*` fields are parameters carried by an action request. Choices and previews made within the same action interface are not recorded as additional actions.

## Most Complex Prerequisite: Intervene in the Transport Network

Of the six actions, `intervene_transport_network` simultaneously depends on flow state, per-stage usage state, player selection, graph structure, operating metrics, resource balance, and balance configuration, and it requires a connectivity validation. Its prerequisite is therefore the most complex.

```text
can_intervene_transport =
    (phase == Phase.OPERATION_DECISION)
    && (active_operation_decision_id != null)
    && (!(active_operation_decision_id in confirmed_operation_decision_ids))
    && (transport_intervention_used == false)
    && (selected_transport_edge_id != null)
    && (selected_transport_edge_id in active_transport_edge_ids)
    && (selected_transport_edge_id in mutable_transport_edge_ids)
    && (transport_pressure >= balance.transport.intervention.unlock_pressure)
    && (development_signal >= balance.transport.intervention.cost.development_signal)
    && (disconnects_required_organs[selected_transport_edge_id] == false)
```

| Subcondition | Data Source |
|---|---|
| `phase == Phase.OPERATION_DECISION` | `StageFlowState.phase`, maintained by the stage-flow controller. |
| `active_operation_decision_id != null` | `StageFlowState.active_operation_decision_id`, supplied by the operations decision currently being processed. |
| `!(active_operation_decision_id in confirmed_operation_decision_ids)` | `StageActionState.confirmed_operation_decision_ids`, the set of already confirmed and irreversible operations decisions in the current stage. |
| `transport_intervention_used == false` | `StageActionState.transport_intervention_used`, from current stage runtime state or loaded save state. |
| `selected_transport_edge_id != null` | `TransportPanelState.selected_transport_edge_id`, from the player’s current transport-network selection. |
| `selected_transport_edge_id in active_transport_edge_ids` | `TransportGraph.active_transport_edge_ids`, from the running transport graph of the current body-city map. |
| `selected_transport_edge_id in mutable_transport_edge_ids` | `TransportGraph.mutable_transport_edge_ids`, from the current stage’s intervention flags for transport edges. |
| `transport_pressure >= balance.transport.intervention.unlock_pressure` | The left value comes from `CityRuntimeStats.transport_pressure`; the right value comes from `BalanceData.transport.intervention.unlock_pressure`. |
| `development_signal >= balance.transport.intervention.cost.development_signal` | The left value comes from `ResourceState.development_signal`; the right value comes from `BalanceData.transport.intervention.cost.development_signal`. |
| `disconnects_required_organs[selected_transport_edge_id] == false` | `TransportGraphValidator.disconnects_required_organs`, calculated from the current transport graph and `StageDefinition.required_organ_ids`. |

# Heartbeat Audio Bed Specification

## Source

`audio/ambient/heartbeat_bed.wav` is a deterministic team-authored PCM source
generated by `tools/build_d25_heartbeat_audio.py`.

| Property | Value |
|---|---:|
| Sample rate | 48,000 Hz |
| Channels | 1 |
| Sample format | Signed 16-bit PCM |
| Source duration | 1,000 ms |
| Peak sample | 7,600 of 32,767 (-12.7 dBFS) |
| Melody, harmony, instrument, or voice | None |
| External sample or external license | None |

The source contains two low-frequency damped impulses. Its first and final
5 ms are silent, so the stable loop has no boundary click.

## Required Stability Mapping

D-21 is authoritative for visual timing.

| Stability band | D-21 frame durations | Required loop interval | Source playback-rate equivalent | Target bed level | Level relative to a 0 dB one-shot |
|---|---|---:|---:|---:|---:|
| `stable` | 420, 120, 100, 360 ms | 1,000 ms | 1.000000 | -16 dB | 0.158 amplitude |
| `strained` | 140, 60, 80, 160 ms | 440 ms | 2.272727 | -12 dB | 0.251 amplitude |
| `critical` | 680, 200, 220, 700 ms | 1,800 ms | 0.555556 | -8 dB | 0.398 amplitude |

The required audio interval and the corresponding D-21 animation-loop total
are identical in every row.

## Transition Rules

- Use the thresholds and hysteresis in `docs/OPERATION_SPEC.md` Table E4 and
  `docs/BALANCE.json`.
- Enter `stable` at or above 75. Recover from `strained` only at or above 70.
- Enter `critical` below 30. Recover from `critical` only at or above 40.
- Do not change the bed while the value moves inside a hysteresis region.
- Start a transition on D-21 relaxed frame 0, never in the middle of a pulse.
- Crossfade the outgoing and incoming bed for 250 ms.
- The bed remains below every one-shot. Muting stops it without pausing
  gameplay, events, or animation.

## Pitch-Distortion Decision

Changing the 1,000 ms source to 440 ms by playback rate shifts pitch by about
14.2 semitones. Changing it to 1,800 ms shifts pitch by about -10.2 semitones.
Both are plainly audible and fail the requirement to avoid obvious pitch
distortion.

Therefore the final implementation must use three separately rendered loops
with the same two-impulse grammar and unchanged low-frequency character, or a
pitch-preserving time-stretch implementation. Simple `pitch_scale` playback is
not acceptable.

## Current Runtime Gap

T-37 currently loads only `audio/ambient/heartbeat_bed.wav` and changes only
`AudioStreamPlayer.volume_db`. It does not change cadence, load one loop per
stability band, or crossfade two ambient streams. The stable fallback WAV is
valid, but the three-band D-25 contract is not executable yet.

The required runtime repair is tracked in
`docs/coord/rework/T-37__from_ACCOUNT_D_d25_heartbeat_timing.open.md`. D-25
must not receive a DONE marker until that repair lands and the three rows above
pass a live cadence and no-hard-cut test.

## Validation

```powershell
python -m unittest tests.test_build_d25_heartbeat_audio -v
python tools/build_d25_heartbeat_audio.py --output audio/ambient/heartbeat_bed.wav
```

The test verifies deterministic bytes, one-second duration, mono PCM16 format,
48 kHz sample rate, safe peak, low DC offset, and silent loop boundaries.

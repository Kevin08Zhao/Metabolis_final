How to run

1. Extract the entire archive.
2. Double-click Metabolis.exe.
3. If Microsoft Defender SmartScreen appears, choose More info, then Run anyway only if this archive came from the expected sender.

Known limitations

- This build is not digitally signed, so Windows may show an unknown publisher warning on first launch.
- Some optional event cues are silent when no matching sound file is available.
- Progress is stored only for the current Windows user and is lost if that user's application data is deleted.

How to run

1. Extract the entire archive.
2. Double-click Metabolis.app.
3. If macOS blocks the first launch, Control-click Metabolis.app, choose Open, then choose Open again.

Known limitations

- Apple Silicon requires macOS 13 or later; Intel requires macOS 11 or later.
- This build is not notarized, so macOS may show an unidentified developer warning on first launch.
- Some optional event cues are silent when no matching sound file is available.
- Progress is stored only for the current macOS user and is lost if that user's application data is deleted.
